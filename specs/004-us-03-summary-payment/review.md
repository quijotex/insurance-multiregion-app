### Specific checks requested
- **CMS backfills.** `backfillMaskedInSummary` **conforms**. It updates only `documentNumber`/`rut` rows whose column is `null`/missing, at the DB layer, on draft and published rows alike, and never touches an editor's `true`/`false`. I checked that Strapi creates the new column with `defaultTo: null` (`@strapi/database/dist/schema/schema.js`), so existing rows really are `null` and the backfill fires. Fresh seeds write `maskedInSummary` explicitly. `backfillTerms` writes the draft only (`status: 'draft'`) and publishes only when `shouldPublishAfterBackfill` says the draft is clean, using the draft `updatedAt` read before the write. Otherwise it logs a warning. That part is correct, but it re-seeds terms an editor removed: R-01.
- **Rich-text renderer: conforms (secure).** It has no `innerHTML`, no `bypassSecurityTrust*`, and all text goes through interpolation. Only the paragraph, quote, heading, list and list-item blocks and the text and link inlines pass. Images, code and unknown types are dropped, and only `true` flags are kept. Links are limited to `https:`, `http:` and `mailto:` by `new URL(...).protocol` (relative or unparsable URLs become text), open with `target="_blank" rel="noopener noreferrer"`, and Angular's URL sanitiser on `[href]` is a second layer. Headings are shifted to `h3`/`h4` under the dialog's `h2`. Nits: R-10, plus R-02 for "empty" content.
- **Double payment and the receipt-only session: conforms.** `pay()` returns early unless the state is idle or rejected, and the state is set synchronously, so a double click calls `PaymentService` once (UT-07). The receipt is written before `navigate(['..','confirmation'], { replaceUrl: true })`. `completePayment` keeps only `{ countryCode, data: {}, receipt }`. `noReceiptGuard` guards steps 1–3, and `receiptGuard` checks the receipt's country. The `switch-confirm.guard.ts` change skips `session.start()` only for the same country while a receipt exists. Since `start()` for the same country now only drops the receipt, this is exactly what lets a reload of the confirmation keep it. Another country still resets the session. The stepper change adds `shown = min(current, steps)`, so the confirmation (`current = 4`) shows every step done, with no `aria-current` and "Paso 3 de 3" on mobile. Earlier steps are unchanged.
- **Masking and the payment rule: conform.** `maskValue` keeps the last 4 code points and fully masks 4 or fewer. The flag comes from `maskedInSummary` and no key is hard-coded in Angular. `simulatePayment` strips everything that is not a letter or digit and rejects a suffix of `0000` on masked fields only. It runs in the browser with no network call. The README and ADR 0006 document the rule and the test values. Test gap: R-05.
- **Accessibility.** The checkbox is a native input with a 48 px hit area, named "*Acepto términos y condiciones" through `aria-labelledby` (label plus link button), with a focus ring. The dialog is a native modal `<dialog>` with `aria-labelledby`. Esc, "Cerrar" and "Entendido" return focus to the link. The alerts use `role="alert"` and are re-inserted on each rejection, so they are announced again. Focus moves to the `h1` on load. Open: R-03 (focus lost while processing), R-06 (dialog body scroll), R-08.
- **Bootstrap for layout only: conforms.** Templates use only `row`, `col-*`, `g-*`, `justify-content-center`, `mx-auto`, `py-4` and `visually-hidden`. The rest is BEM with tokens. The one raw colour is R-07.
- **Tests: mostly conform.** UT-01…UT-09 all exist under `US-03 · FR-XXX` names, and E2E-5 exists. E2E-6 (rejected) was not written. The other spec changes only add `termsAndConditions` and `maskedInSummary` to fixtures, plus the US-02 E2E-3 update to the new summary ("Cambiar plan"). Issues: R-04 (wrong FR IDs), R-05 (missing approved example), R-13.
- **Contracts and models: conform.** The schema adds `termsAndConditions` (`blocks`) and `maskedInSummary` (boolean, default `false`). `CountryDto`, `Country`, `FormFieldDto` and `FormFieldDescriptor` are updated in the same commit (`bda3a59`), and `CountryService` requests `fields[5]=termsAndConditions`. No new endpoint or Public permission.
- **No `any`, no new dependency, fictitious data: conform.** `package.json` files are unchanged. The terms are invented and the links point to `example.com`. The test identities (`1020304050`, `10.006.000-0`, `ana@correo.test`) are fictitious. No token, and the browser calls only relative `/api/...` URLs.

**Verdict: Changes requested** (R-01 is Major; R-02…R-07 are Minor; R-08…R-13 are Nits).
