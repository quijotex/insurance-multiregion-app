# Functional user stories

Entry point of the agentic flow (FLOW.md, step 0b). One file per story: `US-XX.md`.

- Pasted **verbatim** by a human from the business source. No AI involvement.
- AI agents read these files but never edit them: they are the root of traceability
  (`US-XX → spec → ADR → code → tests → review`), so the spec can always be compared
  against the business's original wording.
